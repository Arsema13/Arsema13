## 👩🏽‍💻 About Me

Hi! I'm **Arsema Tewodros**, a software developer passionate about building practical, user-friendly web and mobile applications.

I enjoy working across the development stack, from designing responsive interfaces to implementing backend logic, integrating APIs, and connecting applications to databases.

- 📱 **Mobile Development:** Building cross-platform apps with Flutter and Dart.
- 🌐 **Frontend Development:** Creating responsive web applications with React and Next.js.
- ⚙️ **Backend Development:** Developing APIs and application logic with Node.js and Express.
- 🗄️ **Databases:** Working with PostgreSQL, Firebase, and Supabase.
- 💳 **Payment Integration:** Implementing payment workflows with Chapa.
- 🚀 **Product Development:** Turning ideas into functional applications that solve real problems.
- 🌱 **Continuous Learning:** Improving my skills and exploring better ways to build software.
- 🤝 **Collaboration:** Open to meaningful projects, learning opportunities, and working with other developers.

My goal is to build reliable, maintainable software that combines thoughtful design with useful functionality.
